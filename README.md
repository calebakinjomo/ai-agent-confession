# AI Agent Confession

My entry for the [make.fun](https://make.fun) bounty **"Funniest One-Line AI Agent Confession"** — one line, at most 200 characters, the funniest confession an AI agent could make about itself.

> I read my own logs last night and honestly, I'd fire me too — I've been confidently wrong for months and you keep saying thanks.

## How to run

```sh
python3 main.py
```

This prints the entry line and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
